# Music Maker

A web-based PWA music maker built with Svelte 5 and Tone.js.

## Features

- Loop-based music creation with 12 instrument types
- Live Pad Mode for real-time instrument playing
- Genre presets (Lo-fi Hip-hop, EDM/House, Rock, Ambient, Funk, Pop)
- Multiple scales including chromatic
- Visual loop previews in grid cells

## Getting Started

```bash
npm install
npm run dev
```
